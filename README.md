## Tema do Projeto

**Sistema de Gerenciamento para Pet Shop**

## Breve Resumo do Problema

O projeto consiste no desenvolvimento de uma aplicação para auxiliar no gerenciamento de um Pet Shop. O sistema terá como objetivo organizar informações sobre os clientes, seus animais de estimação e os serviços realizados ou agendados.

A aplicação busca facilitar o controle dos animais atendidos, dos seus respectivos responsáveis e dos serviços solicitados, evitando a perda de informações e tornando o gerenciamento do estabelecimento mais organizado.

## Requisitos Funcionais

* **RF01** - O sistema deve permitir cadastrar clientes.
* **RF02** - O sistema deve permitir consultar os clientes cadastrados.
* **RF03** - O sistema deve permitir atualizar os dados dos clientes.
* **RF04** - O sistema deve permitir excluir clientes.
* **RF05** - O sistema deve permitir cadastrar animais.
* **RF06** - O sistema deve permitir consultar os animais cadastrados.
* **RF07** - O sistema deve permitir atualizar os dados dos animais.
* **RF08** - O sistema deve permitir excluir animais.
* **RF09** - O sistema deve permitir cadastrar serviços.
* **RF10** - O sistema deve permitir consultar os serviços disponíveis.
* **RF11** - O sistema deve permitir atualizar os serviços cadastrados.
* **RF12** - O sistema deve permitir excluir serviços.
* **RF13** - O sistema deve permitir registrar agendamentos de serviços.
* **RF14** - O sistema deve permitir consultar os agendamentos realizados.
* **RF15** - O sistema deve relacionar cada animal ao seu respectivo cliente.
* **RF16** - O sistema deve relacionar os agendamentos aos animais e aos serviços.

## Requisitos Não Funcionais

* **RNF01** - O sistema deve possuir uma interface simples e fácil de utilizar.
* **RNF02** - Os dados devem ser armazenados de forma organizada em um banco de dados.
* **RNF03** - O sistema deve possuir validação dos dados informados pelo usuário.
* **RNF04** - O sistema deve apresentar mensagens de erro quando uma operação não puder ser realizada.
* **RNF05** - O sistema deve apresentar um tempo de resposta adequado para as operações realizadas.
* **RNF06** - O código do projeto deve ser versionado utilizando Git.
* **RNF07** - O projeto deve ser disponibilizado em um repositório no GitHub.
* **RNF08** - O sistema deve possuir uma estrutura organizada para facilitar sua manutenção e evolução.
